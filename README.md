# Sobre mim

Sou estudante de Análise e Desenvolvimento de Sistemas no Centro Universitário Senac e atualmente atuo como estagiário na área de Dados.

Minha trajetória profissional começou na área de logística e operações, onde adquiri experiência com processos, indicadores e acompanhamento de resultados. Essa vivência contribuiu para despertar meu interesse pelo uso de dados na análise de problemas e na melhoria de processos.

Atualmente, estou construindo minha carreira em tecnologia, buscando desenvolver uma base sólida em SQL, Python e Business Intelligence.

No estágio, tenho contato com SQL Server e rotinas de processamento de dados. Paralelamente, desenvolvo projetos acadêmicos e pessoais para colocar em prática os conhecimentos adquiridos durante minha formação.

## Tecnologias e Ferramentas

- **SQL Server e T-SQL:** consultas, manipulação de dados e desenvolvimento de conhecimentos em bancos de dados relacionais.
- **Python e Pandas:** preparação, tratamento e análise de dados.
- **Power BI e DAX:** modelagem de dados, criação de indicadores e desenvolvimento de dashboards.
- **Git e GitHub:** organização, documentação e compartilhamento dos projetos.
